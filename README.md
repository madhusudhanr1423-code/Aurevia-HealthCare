# Aurevia Health Care

A modern healthcare website designed to present healthcare services, build trust, and make essential information easy for visitors to access.

🔗 **Live demo:** https://aurevia-health-care.vercel.app/

## Tech Stack
- React + TypeScript
- Vite
- Tailwind CSS
- Framer Motion

## Features
- Service presentation pages
- Trust-focused design for healthcare visitors
- Fully responsive layout
